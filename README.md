# 🍊 LITTTL. FARM.

제주 서귀포시 보성리 벼락밭의 귤나무를 온라인에서 만나고, 가족과 함께 사계절의 이야기를 기록하는 웹 서비스입니다.

## 🌿 어떤 서비스인가요?

- 실제 벼락밭 나무 코드를 입력해 나만의 귤나무와 연결할 수 있습니다.
- 아직 나무 코드가 없어도 온라인 나무를 먼저 만들고 천천히 서비스를 시작할 수 있습니다.
- 물주기, 안아주기, 귤 따기, 벌레 잡기로 나무를 돌볼 수 있습니다.
- 가족을 초대해 같은 나무를 함께 가꾸고 `우리 이야기`에 일기를 남길 수 있습니다.
- 내 나무에 달린 응원(댓글), 일기 답장, 농장 전체 공지를 실시간 알림으로 받아 볼 수 있습니다.
- 제주 날씨에 따라 화면 분위기가 달라지고, 구름 메시지와 응원으로 이웃 나무와 마음을 나눌 수 있습니다.
- 벼락밭 지도에서 숲과 나무를 둘러보고 이름으로 이웃 나무를 찾을 수 있습니다.
